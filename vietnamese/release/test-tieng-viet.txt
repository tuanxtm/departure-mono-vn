Departure Mono Regular · VER 3 · Version 1.003
Vietnamese adaptation by tuantm. Original font by Helena Zhang.
Install either OTF or TTF; only one desktop format is needed.
Close applications, uninstall an older Departure Mono build, install, then reopen.
WOFF and WOFF2 are for websites. Use multiples of 11 px for pixel alignment.

4. Line metrics
Character advance: 350 units; combining marks: 0; pixel: 50; UPM: 550.
Ascent / descent: 800 / 150. Highest ink: 750 (Ẳ Ẩ Ể Ổ); lowest ink in the full font: -150.
Default lines are 35.7% taller than upstream to fit stacked accents, as approved in VER 3.
